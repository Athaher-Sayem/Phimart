# Phimart — isolated API showcase

Open `index.html` directly or serve this folder with `python -m http.server 8000` and open `http://localhost:8000/`. This is a standalone frontend-only design study; it never contacts the API. Route tabs switch between **illustrative local sample data**, not live JSON. The source-backed paths and organization come from `phimart/urls.py`, `api/urls.py`, `order/views.py`, and `product/serializers.py` on the starting `main` commit (`5094b827`).

The project README contains generic placeholders for another tech stack and unverified endpoints. This page uses the Django and DRF code as its source of truth. No source or configuration files were modified.

## Design direction

Technical poster meets developer portal: ink-black foundations, acid green navigation, electric blue and warm yellow route panels; Archivo Black display, DM Sans body and Space Mono data labels, with offline fallbacks. Square corners and outlined controls intentionally contrast the warm editorial CIFAR-10 showcase.
